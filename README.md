# 北區高中職門徒營｜福音小說網站

整理並展示 **北區高中職門徒營福音小說** 的靜態網站。  
網站收錄不同年度營會所使用的福音小說與相關內容，方便線上閱讀、保存與分享。
使用者可以透過首頁快速進入各年度作品，閱讀故事內容與相關素材。
